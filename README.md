# Grant Application System 🎓

A beginner-friendly Python project that simulates a student grant application system.

The program collects student information and academic grades, calculates the total and average grades, evaluates the student's academic level, and checks basic scholarship eligibility.

## 📌 Project Overview

The **Grant Application System** is a console-based Python application designed to practice fundamental Python programming concepts through a real-world style project.

The application asks the student to enter:

* Name
* Age
* University
* Major
* GPA
* Python grade
* Math grade
* Statistics grade

It then generates an application report containing the student's information, academic results, academic level, and scholarship eligibility.

## ✨ Features

* Collects student information using `input()`
* Converts user input into appropriate data types
* Stores information using Python dictionaries
* Calculates total grades
* Calculates the average grade
* Determines the student's academic level
* Checks basic scholarship eligibility
* Generates a clear application report
* Uses conditional statements to make decisions

## ▶️ How to Run

1. Make sure Python 3 is installed on your computer.
2. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/Grant-Application-System.git
```

3. Open the project folder:

```bash
cd Grant-Application-System
```

4. Run the program:

```bash
python grant_application.py
```

5. Enter the requested student information and grades.
